# Crops for the public page (2026-10-21)

Plain pixel copies of boxes of `artifacts/puzzle.png` (1600 x 1200, sha256
`d0b04378f75d63997b8034ec2ef1bdd108178e4546de78237bd35abf4189a782`), made by `make_crops.py`, which
lists every box. Nothing is super-resolved, sharpened or recoloured: the `_zoom` files repeat
pixels by a whole factor, the two border strips are turned by 90 degrees so they read along, and
`overview_800.png` is the whole picture at half size. `crops.sha256.txt` is the script's output.

The artwork is the puzzle author's (posted by u/stsh_n, 2020-10-08); these files are analysis of
it, not ours to licence. They exist so the public page can show which part of the picture each
section talks about.
