Was it tried?

Search a word or a passphrase against the published search configs and the run ledger.

How to read this

  • The record stops on 2 October 2026. Searches after that are not published, so finding nothing here does not mean something was never tried.
  • A config is a search with a fixed shape. A word being in a config does not mean every phrase with that word was tried. Open the config to see which slots were fixed and which were open.
  • "Finished, no match" means a finished line of the ledger was tied to this config through the queue logs, by its finish time. It rules out that config's exact search and nothing wider.
  • "No run tied to it" means the published ledger cannot name a run for this config. Ledger lines carry a signature, not a config name, so a config may have run before the queue logs began, may have run after the cut-off, or may not have run at all.
  • Words match exactly as a config writes them, because raw configs keep case: moon and MOON are separate searches.
  • Passphrases are compared the way wallets use them. BIP39 keeps case, so MOON and moon are different. Electrum lower-cases, so they are the same.
