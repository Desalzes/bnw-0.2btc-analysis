CPU config builder

Build search configs from BIP39 words and your own words, estimate run time on your CPU, and download ready-to-run files for the public solver.

Runs entirely in this browser tab. Downloaded configs search only the 0.2 BTC prize address (1KfZGvwZxsvSmemoCmEV75uqcNzYBHjkHZ) on your own computer.

    Saved word groups

    1. Seed format

    2. Fixed slots (FIX)

    Click a slot to select it, or drag words onto it. Drop multiple words on one slot for alternatives (word1|word2). Leave empty for open slots.

    3. Required anywhere (REQUIRE)

    Words that must appear once in any of the open slots.

    4. Filler pool (POOL)

    Words used to fill any open slots not taken by required words.

    5. Extra passphrases (PASS)

    One per line. The empty passphrase is always tried automatically.

    6. Derivation paths (PATH)

    7. CPU time estimate

    Averages are rough multi-core estimates for setperm_solve.py (PBKDF2-HMAC-SHA512). Actual speed depends on core count, clock speed, and thermal throttling.
